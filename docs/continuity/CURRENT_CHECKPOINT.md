## Operating phase

DEDAL remains in hardening, consolidation, and outcome-validation mode. Capability expansion is evidence-gated. The current focus is not adding novelty for its own sake, but reducing repeated work, regressions, source drift, and incomplete learning closure.

## Self-Improvement v1

`self-improvement` / `self-correction` is now an independently routable bounded meta-faculty. It activates for meaningful Creator corrections, recurring failures, regressions of previously fixed behavior, live/canonical source drift, verified better recurring procedures, and explicit DEDAL self-improvement work.

Its core invariant is:

> A material fix is not closed until the relevant runtime truth, canonical source, regression guard, durable lesson, and continuity state are reconciled.

The skill orchestrates closure; it does not absorb domain implementation, incident command, independent QA, memory governance, or external skill research. Those remain with their registered owners.

A material production-only hotfix creates explicit **source-sync debt** until canonical source is reconciled. Repeated known failures trigger inspection of the previous learning closure rather than being treated automatically as unrelated fresh bugs.

`evals/self-improvement/closure-contract-v2.json` mechanically rejects durable closure when canonical sync, regression coverage, durable learning, independent verification, or required debt resolution is missing. A public-safe representative regression replay records the real failure pattern that justified this hardening. This is contract/representative incident evidence, not yet a claim of measured long-run improvement.

## YouTube execution/auth state

YouTube Publishing remains the authenticated YouTube execution/transport owner. The normal upload path is now `youtube_upload_submit -> durable Gateway job -> persistent isolated VPS runner -> source retrieval -> resumable upload -> bounded verification -> ready_private`. Per-upload GitHub Actions are no longer the normal execution engine; the manual upload-job workflow is recovery-only.

The persistent runner was live-proven with a disposable private Google Drive upload that auto-picked, uploaded, and reached verified/ready-private state without a per-upload GitHub workflow. The test video was removed afterward.

The DEDAL YouTube MCP canonical OAuth behavior is now the no-intermediate-page Authorization Code + PKCE flow used by Composio DCR. Legacy approval-ticket/approval-page behavior was removed from canonical source. Deployment credentials and live connection state remain private runtime facts and must still be verified live when consequential.
