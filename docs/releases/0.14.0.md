- Focused references for intent/audience/grounding, structure/voice/revision, and multilingual fidelity/terminology.

- `evals/writing-editorial/contract-v1.md` with routing, fidelity, terminology, multilingual, revision, and regression assertions.

## Changed
- Writing work now explicitly separates factual/content truth from expression/style so fluent rewrites cannot silently change claims.
- Rewrites/translations protect semantic invariants including negation, modality, scope, numbers, names, dates, uncertainty, and sequence where material.
- Project/Creator/domain style and terminology outrank generic style-guide preferences.
- Voice is controlled through explicit dimensions rather than a single vague tone label.
- Multilingual work prioritizes meaning and function, uses stable terminology, and treats literal word order as optional rather than the default fidelity metric.
- Roadmap item 5 is now active; Visual Direction / Image Production becomes the next planned capability.
