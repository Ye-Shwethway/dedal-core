# DEDAL Core v0.16.0

Date: 2026-09-14

## Decision / Planning Intelligence v2

Decision Intelligence was merged into the existing `decision-design` skill rather than added as a duplicate top-level capability.

### Added
- decision weight based on reversibility, downside, uncertainty, and blast radius;
- explicit fact/assumption/uncertainty/value/constraint separation;
- critical decision path and dependency-frontier refinement;
- option-preserving bounded experiments;
- commit / continue / stop / revisit thresholds;
- bounded premortem for consequential fragile plans;
- lightweight decision records with confidence and reevaluation triggers;
- post-decision review that separates process quality from outcome luck.

### Evidence
- Amazon one-way/two-way door decision framing;
- NASA Decision Analysis / Risk-Informed Decision Making guidance;
- Gary Klein project premortem;
- Martin Fowler ADR guidance;
- existing Matt Pocock `grilling` adaptation lineage.

### Boundary
Decision Design remains deliberate and anti-ceremonial. Routine, reversible, sufficiently specified work should proceed without forced decision sessions.

No external decision package or executable was installed or run.
