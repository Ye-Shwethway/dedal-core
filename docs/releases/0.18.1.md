# DEDAL Core 0.18.1

_Date: 2026-09-14_

## Summary

Tightens consolidation routing without requiring any Creator-side setup.

## Changed

- Added `state/routing-boundaries.json` with primary ownership for the main overlap clusters: repository lifecycle, state/continuity, data/domain, interface/implementation, evidence/acquisition, and expression/truth.
- Tuned Skill Acquisition so the current hardening phase does not drift back into default skill expansion. Explicit acquisition requests and demonstrated capability gaps remain valid triggers.
- Extended runtime-contract validation so routing clusters cannot silently reference unknown skill owners or lose required overlap coverage.
- Deferred native-provider GitHub interception unless a controllable dispatcher becomes available; no manual Creator setup is required.
- Advanced the executable checkpoint to `ROUTING-OUTCOME-01`, which uses ordinary real work for outcome evidence before MERGE/REMOVE decisions.

## Evidence standard

This release improves contract-level routing clarity. It does not claim measured global efficiency gains or justify new MERGE/REMOVE decisions yet.
