# DEDAL Core 0.18.3

_Date: 2026-09-14_

## Summary

Adds a lightweight executable trajectory-evaluation contract after auditing current tracing, eval, replay, and observability patterns. No new skill and no telemetry platform were added.

## Sources reviewed

- OpenAI Agents SDK tracing guidance: typed workflow traces/spans for agent, model, tool, guardrail, handoff, and custom events.
- `harness/harness-evals` pinned at `dc742e28cee08e1db95b65afce49fbdf9ae3ab5c` (Apache-2.0).
- `nderman/agent-harness` pinned at `c0253dd6b0e9ada5e8bf45bded9c89f6c730daaa` as a community reference for deterministic record/replay and trajectory regression design.

No third-party package or runtime was installed or executed.

## Adapted

- Tracing and evaluation are explicitly separate: traces describe execution; evals judge whether the trajectory and outcome satisfy the contract.
- Core observability defaults to privacy-minimal typed metadata rather than raw prompts/responses or hidden reasoning.
- Added `evals/trajectory/contract-v1.json` with deterministic positive/negative cases.
- Runtime-contract CI now checks bounded retry references, verification after successful mutations, evidence-linked accepted-state promotion, event sequence/type/status integrity, and rejection of raw prompt/response/reasoning fields.
- Real observed failures should become the smallest regression case that protects the violated invariant.
- Record/replay is reserved for a stable controllable seam; offline replay is not treated as proof against live-model drift.

## Rejected as defaults

- Full raw conversation tracing in public Core.
- Persisting chain-of-thought or private scratchpads for observability.
- Building an OpenTelemetry backend/dashboard before a concrete operational need exists.
- LLM-judge-only evaluation where deterministic assertions are available.

## Evidence level

The trajectory policy is executable contract validation. It does not yet prove better real-task outcomes. The next checkpoint requires genuine ordinary-task trajectory evidence and the first real failure-derived regression case when one is observed.
