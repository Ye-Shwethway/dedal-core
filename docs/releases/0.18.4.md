# DEDAL Core 0.18.4

_Date: 2026-09-14_

## Summary

Turns context-engineering lessons into an executable DEDAL contract without adding a new skill or adopting a vendor-specific memory runtime.

## Sources

Reviewed Anthropic context-engineering/managed-agent guidance, OpenAI current agent compaction direction, `langchain-ai/context_engineering` pinned at `c1a78c1d7f466f68924624f280fd3c0b9742fd29`, and public Letta context/memory architecture material.

No third-party package, notebook, runtime, or script was installed or executed.

## Adapted

- Context management is modeled as four distinct operators: **write, select, compress, isolate**.
- Retrieval is reference-first and just-in-time when possible.
- Selection considers authority and freshness in addition to relevance.
- Volatile live state must be refreshed when staleness could change the next action.
- Compaction is treated as lossy and must preserve protected decision anchors plus recoverable source/reference identity where relevant.
- Old raw tool/history material is the preferred compaction/drop target before accepted decisions or authority boundaries.
- Isolated work must return compact evidence/conclusions/uncertainty/references rather than a full transcript dump.

## Executable contract

Added `evals/context-engineering/contract-v1.json` and a dependency-free validator. Runtime Contracts CI now checks positive and negative cases covering:

- stale live-state selection without refresh;
- protected-state loss during compaction;
- compaction without recoverable source identity;
- valid reference-first retrieval;
- valid compact isolation handoff;
- invalid isolation with no compact return contract.

## Rejected as defaults

- Loading all potentially relevant context merely because the window is large.
- Semantic similarity as the sole retrieval criterion.
- Irreversible prose summaries replacing canonical live sources.
- Automatic multi-agent fan-out for context isolation.
- Vendor-specific context/memory runtimes as Core dependencies.

## Evidence level

This release is external-pattern audit plus contract validation. It does **not** prove lower token use, lower latency, or improved real-task outcomes; those claims require representative observable evidence.
