# DEDAL Core 0.18.5

_Date: 2026-09-14_

## Summary
Adds a controlled self-improvement discipline without creating a new skill or granting DEDAL broader autonomy.

## Learned pattern
High-signal self-improving harnesses converge on a control loop: observed failure -> bounded hypothesis -> isolated candidate -> comparable eval -> regression inspection -> retain/revert. Evaluation is the control layer that separates self-improvement from uncontrolled self-modification.

## Added
- `evals/self-improvement/contract-v1.json` with positive and negative experiment cases.
- `scripts/validate_self_improvement_contract.py`, dependency-free and CI-executed.
- Self-improvement rules in Agent Engineering self-application guidance.
- Audit note recording external influences and rejected defaults.

## Enforced principles
- material changes need a comparable baseline;
- candidate changes must not modify their own protected eval contract;
- known-failure checks should be paired with held-out/regression coverage when material;
- task-specific benchmaxxing is invalid;
- retaining a candidate with a known regression is invalid;
- revert and inconclusive are valid outcomes;
- external benchmark gains are not DEDAL outcome evidence.

## Not added
- no autonomous unbounded self-rewrite loop;
- no new top-level skill;
- no new permissions;
- no claim of measured DEDAL quality or efficiency improvement.

## Evidence level
External-pattern audit plus executable contract validation. Representative real-task outcome evidence is still required before stronger claims.
