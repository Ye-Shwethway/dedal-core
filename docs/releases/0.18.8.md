# DEDAL Core 0.18.8

Final agent-refinement slice before pausing the current hardening campaign.

## Added

- executable failure-recovery contract covering retry safety, compensation order, partial completion, irreversible residual effects, and compensation failure;
- dependency-free CI validator for the contract;
- Agent Engineering guidance for retry / compensate / preserve-partial / escalate semantics;
- external pattern audit for saga/compensating-transaction concepts.

## Key rules

- failure does not automatically mean retry or rollback;
- retry side-effecting operations only when repetition is explicitly safe/idempotent;
- compensation across external systems is a semantic counter-action, not ACID rollback;
- do not claim full rollback while irreversible residual effects remain;
- partial completion must disclose residual effects and blocked actions;
- failed compensation escalates to manual/incomplete recovery rather than successful completion;
- prefer preflight prevention and local atomic transactions where they are sufficient.

## Evidence level

Contract validation only. No global reliability, incident-rate, latency, or task-success improvement is claimed.

## Campaign status

The current agent-refinement learning campaign is paused after this release. Existing outcome checkpoints remain valid and should accumulate naturally during ordinary work rather than through synthetic tasks.
