# DEDAL Core 0.19.1

## Capability-gap map

This release records an ecosystem-wide Agent Skills capability-gap audit without adding a new active skill.

### Decisions

- Quality Engineering is the first top-level promotion candidate.
- Cloudflare Platform is the second top-level promotion candidate.
- Database Engineering is a third candidate, but should start from reference packs and outcome evidence.
- Flutter, Android, Postgres/Supabase/Neon, Terraform/IaC, observability/SRE, and browser/computer automation remain reference-pack-first.
- Healthcare/clinical-informatics acquisition remains a later, high-bar area with bounded workflows and current authoritative evidence.
- Browser/computer control is treated as an execution surface rather than an independent faculty.
- Bulk marketplace imports, popularity-driven acquisition, thin duplicate vendor wrappers, and weakly grounded generic medical/persona skills are rejected as top-level expansion strategies.

### Evidence boundary

This release establishes discovery, source pins, ownership analysis, and promotion order only. It does not claim that the candidates improve task outcomes. Each promotion still requires a deep audit, representative baseline, regression review, and deliberate activation.
