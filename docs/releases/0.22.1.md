# DEDAL Core 0.22.1 — Mobile Reference Pack

## Summary

Audit official Flutter and Android agent-skill corpora and deliberately keep mobile development as progressive reference knowledge under existing DEDAL owners instead of promoting a duplicate top-level Mobile Engineering faculty.

## Changes

- Add `skills/software-development/references/mobile-flutter-android.md` with scoped Flutter/Android architecture, testing, toolchain, device-evidence, and freshness guidance.
- Add the mobile deep-audit provenance note under Skill Acquisition references.
- Add executable mobile reference-pack routing cases and CI validator.
- Route Flutter/Android implementation through Software Development; responsive UX through Interface Design; independent mobile QA through Quality Engineering; APK/AAB/store promotion through Release Engineering; local DB semantics through Database Engineering.
- Explicitly reject creating a top-level Mobile Engineering owner merely because a project uses Flutter or Android.
- Require live official verification for drift-sensitive Flutter/Dart/Android/AGP/Gradle/Kotlin/JDK/SDK/Play/plugin/tooling facts when material.
- Move the next capability audit to Observability/SRE, still reference-first.

## Evidence boundary

This release validates routing and captures first-party methodology. It does not claim measurable outcome improvement yet. Real Flutter/Android work should provide future outcome evidence for the reference pack and for whether a broader mobile owner is ever justified.
