# DEDAL Core 0.27.0 — YouTube Public Source Sync

Date: 2026-09-16

## Why this release exists

The previous YouTube hardening release recorded a verified gap between live deployed behavior and the public source snapshot. This release closes the public-safe implementation gap using the authorized `YOUTUBE-SOURCE-SYNC-01` handoff and Library working mirror, without copying deployment-only artifacts into the public repository.

## Synchronized source

- Gateway external HTTPS media fetch guards, redirect/private-host checks, MIME/size bounds, stage-aware diagnostics, captions, thumbnails, playlist images, banner handling, watermark safety boundaries, bounded Data/Reporting/Analytics bridges, and dedicated video deletion.
- `playlist_image_state` migration for managed playlist-image replacement and rollback.
- MCP registry/routing expanded to 49 bounded `youtube_*` tools.
- Runtime Contracts now execute the YouTube source-sync and public-repo privacy validators.

## Public source versions

- Gateway: `0.4.0`
- MCP: `0.2.0`

Authorized deployed references used for reconciliation were Gateway `0.7.35` and MCP `0.8.1`. Public versions intentionally follow repository source evolution rather than deployment patch numbering; this release does not assert byte-for-byte parity with raw deployed Worker exports.

## Privacy boundary

The public source excludes credentials/tokens/cookies, Creator-specific resource identifiers, raw D1/audit rows, live media URLs, internal test assets, embedded debug media, raw Worker exports, and Cloudflare account/database identifiers. Production D1 identity is supplied outside the public repository.

## Validation

Repo integrity/runtime contract gates, YouTube hardening/source-sync contracts, Node/Python syntax checks, diff checks, and the public-repo privacy scanner must pass before promotion.

## Remaining limits

Banner persistent managed rollback is not yet at playlist-image parity. Watermark prior state remains unreadable, so unmanaged destructive handling remains fail closed. Prior YouTube Analytics upstream-read issues are not claimed resolved by this source synchronization.

## Next checkpoint

`YOUTUBE-PUBLIC-SOURCE-OUTCOME-01`: exercise the synchronized public source in normal maintenance/deployment work and record only observed drift/regressions.
