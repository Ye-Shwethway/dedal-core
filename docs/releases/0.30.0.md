# DEDAL Core 0.30.0 — YouTube Discovery Intelligence

## Purpose

Promote YouTube SEO from a small publishing rule into an independently routable discovery-intelligence faculty while preserving YouTube Publishing as the authenticated execution owner.

## Evidence base

- Current first-party YouTube/Google Search, Data API, Analytics, Reporting, Studio Trends, CTR and experiment documentation.
- External skill/repository audit covering open-source YouTube SEO/marketing/analytics patterns and review-gated SEO pipelines.
- Live read-only YouTube evidence through the existing DEDAL MCP: owned-channel search terms/Analytics summaries and bounded public search-landscape observations.

## Key contract

`youtube-seo` owns research, diagnosis, packaging hypotheses, experiments and learning. `youtube-publishing` owns authenticated channel targeting, API/MCP mutation transport, upload/publication state and read-back. An SEO recommendation never grants mutation authority.

## Truth discipline

The skill does not invent absolute YouTube search volume, universal keyword difficulty, guaranteed ranking, universal CTR benchmarks or causal conclusions unsupported by the evidence. Opportunity is represented as inspectable factors with provenance.

## Private learning

Channel-specific search terms, resource identifiers, analytics evidence and durable Creator lessons belong in the Library-only private operational overlay. Public Core contains only sanitized generic methodology.

## Known engineering gaps

- Extend the typed YouTube search surface with useful official search controls such as region/language/time/pagination where justified.
- Repair and live-validate the current Reporting API transport before Reach impressions/CTR become a hard dependency.
- Add typed retention/per-video analytics helpers after the exact report templates are validated.
