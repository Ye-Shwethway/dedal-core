# DEDAL Core 0.33.0 — Facebook Page Management

## Added

- New `facebook-page-management` specialist platform skill.
- Exact managed-Page identity and authority gates.
- Safe Page content lifecycle rules for text, photo, video, scheduling, moderation, analytics, administration, and conditionally verified Messenger workflows.
- Capability evidence states: exposed, authorized, read-verified, write-verified, degraded.

## Public/private boundary

The public Core contains only reusable Page-management rules and sanitized live-gate evidence. Real Page/account identifiers, private analytics/messages, content calendars, audience strategy, credentials, and Creator-specific Page behavior remain outside the public repository.

## Validation evidence

Representative live tests verified Page CRUD/media/scheduling/analytics operations. Messenger remained degraded and therefore is explicitly gated rather than overclaimed.
