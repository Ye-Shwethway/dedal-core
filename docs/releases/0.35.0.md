# DEDAL Core 0.35.0 — Visual Narrative Production

## Summary

Core 0.35.0 upgrades the former Visual Direction image skill into a broader **Visual Narrative Production** faculty and adds **Story Weaver** as the narrative/canon owner. The change is designed for visual-novel and sequential-image workflows where professional quality depends on story-beat selection, recurring character consistency, environment continuity, camera grammar, performance, anatomy/contact mechanics, and rendered QA rather than isolated prompt writing.

## Migration

- Canonical owner: `visual-narrative-production`
- Legacy alias: `visual-direction`
- There is one implementation; the alias does not create duplicate routing ownership.
- Story canon/scene/beat/dialogue work routes to `story-weaver`; image/shot production routes to `visual-narrative-production`; temporal assembly routes to `video-production`.

## New contracts

- shot specification schema;
- Visual Continuity Ledger schema;
- narrative-to-shot planning;
- expression/performance direction;
- cinematography and screen-direction continuity;
- environment/lighting continuity;
- pose/anatomy/contact/load QA;
- provider-agnostic prompt compilation and benign-scene semantic neutralization;
- role-specific accepted-anchor promotion.

## Privacy boundary

The public Core contains generalized lessons only. Private character references, images, canon, and project-specific regression fixtures remain in private overlay/project state.
