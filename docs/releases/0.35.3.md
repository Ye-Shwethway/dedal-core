# DEDAL Core 0.35.3 — Pixel-Bound Visual Continuity

## Summary

Visual Narrative Production now hardens recurring-character generation around **actual visual reference binding**, explicit scene geometry, and a strict separation between environment continuity and camera composition.

## Key changes

- Canonical recurring-character image anchors must be passed to the generation execution surface as pixel-bearing/provider-supported image references when consistency is material. Merely retrieving or visually inspecting a stored image does not count as conditioning.
- Text traits supplement canonical images but do not silently replace them. Unsupported reference binding must be disclosed rather than described as a locked identity workflow.
- Environment anchors preserve place identity, layout, materials, recurring objects, and light/time state, but do not freeze a background plate across different viewpoints.
- Movement/action shots now preflight start position, destination/action target, movement/facing direction, gaze target, camera side/axis, and landmark visibility.
- Identity visibility should be solved through camera placement, not implausible head turns or action-inconsistent gaze.

## Privacy boundary

This release contains generalized workflow lessons and regression contracts only. No private character identities, project-specific images, or private prompts are included.
