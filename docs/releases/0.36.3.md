# 0.36.3 — File-Mediated Creative-Agent Bridge

This release adds a durable agent-collaboration contract for workflows where DEDAL prepares validated source states and a separate specialist agent executes generative-video production or another downstream creative stage.

## Added
- portable file-mediated bridge architecture;
- manifest-version-pinned JSON handoffs and lifecycle semantics;
- validated `images_ready` admission;
- pairwise reachability and exact frame-pair feedback for narrow repair;
- explicit polling/asymmetry capability honesty;
- public/private separation for connected-workspace details.

## Boundary
The public repository does not contain private workspace links, character/project identifiers, or deployment-specific access details. Those belong to the private overlay or connected service.
