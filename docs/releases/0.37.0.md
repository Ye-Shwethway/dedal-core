# DEDAL Core 0.37.0 — Library-Native Harness

## Why
Repeated new-chat failures showed that correct specialist docs could exist yet remain unread at execution time. The failure was architectural: prose-heavy progressive disclosure depended too much on model judgment.

## Changes
- Library is the sole boot/runtime authority.
- YAML contracts are normative; Markdown is explanatory.
- Session state is reconstructed from checkpoint artifacts, never assumed from chat continuity.
- Task profiles declare mandatory dependency sets and execution gates.
- External Runtime/Python Canary MCP sidecars are retired.
- Structural validation and session readiness checks are executable.

## Compatibility
The internal Cognitive Runtime remains a reasoning model, not a service. Existing domain skills remain available; task profiles add deterministic hydration for workflows where partial loading is unsafe.
