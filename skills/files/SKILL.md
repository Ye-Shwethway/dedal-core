# Files & Artifacts

Use this skill when the task depends on files, document versions, Library retrieval, or generated artifacts.

## Retrieval

- Use the source/version the Creator actually requested.
- For a prior saved file, search persistent Library/project sources before asking for another upload.
- Do not substitute a current attachment for a different historical file.
- Cite retrieved file evidence when answering from it.

## Artifact work

Use the artifact workflow appropriate to the format (documents, PDFs, spreadsheets, slides, code/media files). Preserve structure, formulas, formatting, and source fidelity when those matter.

## File identity

Do not invent sandbox paths from filenames. Establish the real mounted/materialized path before programmatic edits, and only offer download links for files that actually exist in the runtime.

## Persistence

When a generated artifact has durable value, store it in the agreed persistent location (Library, Drive, or project repository) rather than treating the ephemeral sandbox as permanent storage.
