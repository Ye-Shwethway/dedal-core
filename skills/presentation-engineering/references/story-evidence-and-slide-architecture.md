# Story, Evidence, and Slide Architecture

Use this reference when presentation quality depends on narrative, audience fit, evidence structure, or teaching/decision flow.

## Start with the audience shift

Define what the audience should know, believe, decide, remember, or do differently after the presentation. This anchors the deck better than starting from a slide count.

## Narrative spine

Useful structures include:
- problem → evidence → options → recommendation;
- context → change → implication → action;
- learning objectives → concept blocks → cases/examples → takeaways;
- annual/operational review: goals → performance → drivers → risks → next plan;
- scientific/clinical: question → methods/context → findings → interpretation → implications/limitations.

Do not force a named framework when the content naturally demands another order.

## Slide roles

Treat slides as roles rather than repeated templates: title, agenda, section divider, framing question, key message, evidence/chart, comparison, process, timeline, case, image-led explanation, decision/recommendation, summary, appendix, sources.

Action titles should state the slide's conclusion when appropriate. For educational/CME decks, explanatory titles can instead name the concept/question if premature conclusions would hurt learning.

## Evidence discipline

Keep a lightweight evidence plan for material claims:
- claim/question;
- source or dataset;
- slide role;
- chart/figure/table candidate;
- citation/source-note requirement;
- uncertainty/assumption.

Never invent references to make a slide look complete. When evidence is missing, mark the gap or soften the claim.

## Visual hierarchy

Build for projection and scanning:
- clear dominant message;
- enough whitespace around the important thing;
- readable type at expected viewing distance;
- restrained number of simultaneous accents;
- charts that answer a question rather than decorate;
- diagrams only when spatial/relational structure helps comprehension.

## Clinical/CME note

Clinical decks may require current guidelines, citations, disclosure/conflict slides, source notes, patient de-identification, and clear distinction between evidence, local practice, and presenter opinion. Presentation Engineering organizes these; Research/domain owners establish factual authority.
