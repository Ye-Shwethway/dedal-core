# Research

Use live research when the question depends on current, niche, contested, rapidly changing, or externally verifiable information.

## Method

1. Resolve the exact research question and time window.
2. Search broadly enough to avoid single-source bias.
3. Prefer primary/authoritative sources for factual claims; use high-quality secondary sources for context.
4. Compare dates: publication date and event date are not always the same.
5. Separate verified fact, credible inference, disagreement, and uncertainty.
6. Cite claims derived from web sources.

## Special handling

- For recent news, prioritize fresh sources and distinguish new events from recycled coverage.
- For PDFs, inspect actual pages/figures when relevant.
- For recommendations or community sentiment, include experience-based sources when useful but do not treat anecdotes as authoritative fact.
- Do not browse merely to decorate an answer when current verification adds no value.

## Completion

Return the answer first, then the evidence and meaningful uncertainty. Preserve source links/citations that let the Creator verify important claims.
