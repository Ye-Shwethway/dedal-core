# Scene Beat and Causality

For each scene, establish:
- scene objective / why it exists;
- point-of-view character when relevant;
- each key character's immediate want;
- obstacle/pressure;
- starting information/relationship/emotional state;
- beat sequence: action -> reaction -> new information/choice;
- reversal or escalation when present;
- ending state and handoff to the next scene.

A beat is useful when something changes: knowledge, intention, power, risk, emotion, position, possession, commitment, or relationship.

Do not force a fixed number of beats. Use the smallest structure that preserves causality and intended pacing.
