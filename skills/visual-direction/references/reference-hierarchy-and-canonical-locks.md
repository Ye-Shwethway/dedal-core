# Reference Hierarchy and Canonical Locks

## Why hierarchy matters
Multiple references can disagree. Resolve authority by dimension rather than averaging them mentally.

Recommended reference roles:
- **identity anchor** — face/subject identity and stable age/ethnicity-neutral visual structure;
- **body/shape anchor** — physique, proportions, silhouette, posture;
- **grooming anchor** — hair, beard, makeup, scars/tattoos when relevant;
- **wardrobe/prop anchor** — clothing, equipment, accessories;
- **composition anchor** — framing, camera angle, pose, spatial arrangement;
- **style anchor** — medium, rendering language, grade, texture, lighting character;
- **environment anchor** — location/set/architecture/background logic.

A single image may fill several roles, but do not assume that by default.

## Canonical trait sheet
For recurring subjects, keep a compact trait sheet:
- invariant identity traits;
- allowed variation range;
- era/age state;
- body/proportion state;
- grooming state;
- distinctive features;
- explicit anti-drift notes;
- approved anchor image IDs/locations.

Separate **must preserve** from **may vary**. Over-constraining every visible detail reduces useful variation; under-specifying identity permits drift.

## Conflict handling
When references conflict:
1. identify the conflicting dimension;
2. choose the authoritative reference for that dimension;
3. state which reference is only inspiration;
4. do not silently blend mutually exclusive traits;
5. if authority is unresolved and materially affects the result, surface the ambiguity.

## Promotion rule
An output becomes a new canonical anchor only after explicit acceptance or strong project evidence. A visually attractive but identity-drifted image is not a valid anchor for the same subject.
