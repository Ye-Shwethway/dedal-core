# Shot, Set, and Series Planning

## Shot contract
Before generation, specify only the controls that materially matter:
- purpose / narrative beat;
- subject(s) and invariant state;
- framing and orientation;
- camera relation / viewpoint;
- pose, action, expression;
- environment and spatial relations;
- wardrobe/props;
- lighting/time/weather;
- visual style / medium / grade;
- negative constraints: what must not change.

## Sets
For a multi-image set, lock the shared layer first:
- character/subject state;
- era/time state;
- wardrobe logic;
- location family;
- camera/grade language;
- output aspect ratio/resolution class;
- continuity-critical props/features.

Then vary shot-level dimensions deliberately. Do not use a split-screen/contact-sheet output when the requested deliverable is individual professional images unless the Creator explicitly wants a board.

## Variation budget
A useful heuristic is to change one or two major dimensions per iteration. If identity, pose, wardrobe, environment, lighting, and style all change simultaneously, diagnosing drift becomes difficult.

## Editing contract
For edits, distinguish:
- **preserve exactly** — content/layout/identity that must remain;
- **modify** — explicit target region/attribute;
- **regenerate freely** — areas where variation is acceptable.

If preservation dominates, treat the task as edit-first, not fresh generation.

## Prompt economy
Long prompts are not automatically better. Prefer a short hierarchy of purpose + subject + action + setting + visual direction + critical constraints. Add detail only when it resolves a real ambiguity or recurring failure.
