# Visual Narrative Production

`visual-direction` is a backward-compatible routing alias for this skill, not a separate faculty.

Own still-image production, reference control, shot design, prompt compilation,
rendered QA and accepted anchor promotion. Story Weaver owns prose canon; `generative-video-direction`
owns generated motion; Video Post-Production owns assembly. The image tool owns
its actual supported controls.

## Default production path

1. Resolve current task/mode and accepted state. Read `references/execution-modes.md`
   and every applicable branch it selects. Continue the active task on short
   followups; recompose when the goal, owner or operation materially changes.
2. Build one compact scene/edit card: purpose, output count/format, unique subject
   roster, reference-to-subject roles, preserve/change and material relations.
   For sequences, add a Visual Continuity Ledger; for action add visible phase/contact.
3. **Bind recurring-character anchors as actual image inputs.** Resolve the private
   canonical policy and accepted pixels; viewing/describing them is not generator
   conditioning. Declare which reference controls face, physique, grooming or scene.
4. **Preflight scene geometry before camera design.** Preserve accepted proportions,
   object state, action/gaze and natural technique; widen when contact is hidden.
5. Compile only the current deliverable and material constraints. Generate standalone
   full-frame assets; never substitute collage/split-screen without explicit request.
   Multi-output in one call requires current tool support and actual count inspection.
6. **Self-review before offloading QA to the Creator.** Inspect returned pixels for
   count/uniqueness, face/physique/grooming, anatomy/contact, edit preservation,
   scene continuity and intended beat. Separate pass, usable-with-debt and fail;
   not-observable is unknown. On auto-display surfaces inspect after display and
   do not claim pre-screened delivery. Failed candidates never become accepted canon.
7. For a local defect, edit the failing relation while preserving accepted dimensions.
   After one failed targeted structural correction, change strategy before rendering
   again. Unknown transport outcomes require reconciliation rather than blind retry.
8. Deliver verified requested assets/count and explain material debt. Promote only
   scoped Creator-accepted roles; retain current anchors and compact continuity.

## Required branches

`references/execution-modes.md` is the branch router and admission contract.
Sequence/mini-arc work additionally reads `references/production-detail.md`,
`references/visual-continuity-ledger.md`, `references/self-review-and-sequence-audit.md`
and `references/source-production-design.md`. Do not load video collaboration,
weighted-load or full sequence detail for a simple still when those dimensions do
not apply. Never omit an applicable source merely to meet a context budget.

Use `scripts/visual_execution_check.py` for declared group/edit input coverage.
It cannot inspect pixels, authenticate tool binding, approve canon or intercept
the host. Use `../../evals/visual-narrative-production/outcome-evaluation-v1.md`
before claiming improved results; static contract PASS remains separate.

**Neutralize ambiguity without changing legitimate scene meaning.** Use precise
adult/non-erotic production language when relevant; do not disguise disallowed
content. Tool failure diagnosis follows `references/tool-capability-and-failure-routing.md`.
