# Narrative to Shot Planning

## Goal
Turn story truth into a small set of purposeful visual beats before generation.

## Beat extraction
For each scene, identify:
- scene objective and conflict;
- arrival/setup state;
- information reveal;
- emotional pivot;
- interpersonal change;
- physical action or decision;
- aftermath/exit state.

Not every prose beat deserves an image. Select a visual beat when a still can materially improve one or more of:
- spatial understanding;
- character-state understanding;
- emotional impact;
- action readability;
- reveal/suspense;
- continuity into later shots;
- iconic/memorable story representation.

## Scene-geometry preflight
Before selecting camera placement for movement or action, write a compact geometry statement:
- subject start position;
- destination or action target;
- movement vector / facing direction;
- gaze target when the action implies one;
- relevant landmarks/props and their relative positions;
- camera side/axis;
- which landmarks should be full, partial, occluded, or offscreen from that camera.

The shot must obey this geometry. A side-entry shot, for example, may legitimately hide the destination object or show only part of it; forcing the destination into a full frontal display can make the subject appear to move in the wrong direction. Preserve **place identity**, not a copied background plate.

For sequential movement, verify that shot N's end state plausibly becomes shot N+1's start state.

## Shot role
Classify the planned image as one primary role:
- establishing/context;
- interaction/two-shot;
- reaction/performance;
- reveal;
- action/impact;
- insert/detail;
- emotional pivot;
- aftermath;
- transition/bridge.

A shot may serve secondary roles, but one primary job keeps composition decisions coherent.

## Coverage logic
For a sequence, plan coverage before rendering:
1. establish geography if location relationships matter;
2. show the action/interaction with readable blocking;
3. cut closer for performance or decisive detail;
4. preserve screen direction and eye lines unless crossing the axis is deliberate and motivated;
5. end on a state that hands off cleanly to the next beat/scene.

## Selection discipline
Do not select a moment only because it is visually attractive. Prefer a moment whose visual state advances narrative information or creates a durable continuity anchor.
