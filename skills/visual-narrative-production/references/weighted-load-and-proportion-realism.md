# Weighted Load and Proportion Realism

## Scope

For workout, training, labor, carry, or other resistance-bearing imagery, visible load is part of physical and character realism. Apply this to all resistance modalities, not only dumbbells:

- dumbbells and barbells;
- kettlebells and plates;
- cables / machine stacks;
- sandbags and medicine balls;
- sleds, carries, loaded implements;
- weighted vests, belts, chains, ankle/wrist loads;
- bodyweight-plus-load movements;
- any visible resistance device.

## Planning rule

Before generation, define when material:

- movement/exercise family;
- performer proficiency / strength envelope;
- intended effort class (warm-up, working set, heavy, near-failure, recovery);
- equipment type and count;
- intended load class or exact visible label;
- whether labels are intentionally visible, hidden, or absent;
- support/contact state;
- expected movement-form consequences of the load.

Do not allow the image model to invent load logic independently in each frame.

## Strength realism

Load should be plausible relative to the performer, exercise, and technique. Related movements should have a coherent strength hierarchy (for example, strict isolation work normally uses less external load than major compound pressing/rowing for the same athlete). Exact numbers are context-dependent; preserve plausibility rather than hard-coded universal weights.

When a visible load changes, show or justify the swap. A transition from light isolation implements to heavier compound implements should include set-down/pick-up states when continuity matters.

## Label continuity

Visible weight numbers, plate counts, stack pins, vest plates, chain count, or other load markers become continuity facts.

- Do not switch numbers between adjacent shots without a visible load change.
- Do not randomly alternate labeled/unlabeled states when the same implement remains in use.
- Matching left/right implements should carry coherent load markings.
- If a label is unreadable or uncertain, do not invent a precise value in the continuity ledger.

## Prop/equipment integrity

Track count, topology, size class, label/load, placement, possession, and contact. Reject fused dumbbells, impossible bar sleeves, merged plates, distorted kettlebell handles, floating/penetrating on-body loads, or other morphology failures.

## On-body weighted work

Weighted vests, belts, chains, or plates must follow gravity and attachment/contact logic. Added load should visibly affect setup and movement mechanics when material; it must not float or clip through the performer/support surface.

## Proportion and framing protection

Camera/framing must not create a false body type when canonical proportion matters. For tall characters, preserve long-leg/tall-read proportions; if the frame is too tight, widen or move the camera rather than compressing the body. Treat recurring body-hair/grooming signatures as identity continuity when visible.
